# Exact Figma heading outlines

These SVGs preserve the actual DIN Medium letter shapes in the supplied Figma design. They were exported read-only from file `zG4AtbXGTFPag9dmRIsR3y`; the source design was not changed.

Each filename is its source node ID with the colon replaced by a hyphen. `manifest.json` records the original text, dimensions, typography, layout bounds, and glyph bounds. All SVGs have a canvas matching the original text node's width and height, preserving the internal glyph offset so they can be positioned directly in the corresponding layout box.

Use these as presentation graphics inside semantic headings, with the original text available to assistive technology. These are exact text-specific artwork exports, not installable fonts. New or edited heading copy still needs the original DIN Medium font or a chosen fallback.
